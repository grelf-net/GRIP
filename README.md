# GRIP
GR's Image Processor. Developed for astrophotography this provides special features that are often lacking from more widely available applications.

GRIP is written in Java and requires Java 8. GRIP.jar is the main part but it uses other libraries. More details at https://grelf.net/download_app.html

CometsFixed.pdf describes how to stack images of faint comets using GRIP and some other free software.
